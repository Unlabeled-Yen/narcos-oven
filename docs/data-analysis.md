## 💥 憲章實例（本次分析發現的靜默失效）

**bug**：初版 `isinstance(c22, (int, float))` 檢查未通過——Excel 常把數字存成字串 `'2'` 而非 int。結果 c22>1 訂單本應有 **17 筆**，初版靜默返回 **0 筆**、產出報表寫「0 筆」。

修正：加 `to_num()` helper 統一處理 str/int/float。

**啟示**：Domain code 每個 numeric 欄位都要走 `to_num`，不能信 Excel 的資料型態。
